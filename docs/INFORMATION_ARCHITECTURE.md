# Information Architecture

```
AthleteOS
├── Marketing
│   └── /                  Landing, philosophy, Day 27 preview
├── Onboarding
│   └── /onboarding        Identity → Body → Lifestyle → Roadmap
└── Operating System
    ├── Today
    │   ├── /dashboard     Daily home
    │   ├── /mission       Brief + lock state
    │   ├── /workout       Strength / mobility engine
    │   └── /run           Aerobic module
    ├── Fuel
    │   └── /nutrition     Indian foods + logs
    ├── Mind
    │   └── /coach         AI coach
    ├── Progress
    │   ├── /progress      Body, photos, achievements
    │   └── /analytics     Insights
    └── System
        └── /settings      Units, privacy, export
```

## Navigation

Desktop: persistent left rail + keyboard `⌘⇧` shortcuts.  
Mobile: five-tab bar (Dashboard, Mission, Workout, Run, Nutrition). Secondary surfaces via settings/progress links.

## Object model

User → Profile/Targets → Day → Mission → Tasks  
Day → Workout → Exercises  
Day → Nutrition / Water / Sleep / Run  
User → Measurements / Achievements / Coach thread / Streak
